# CEIOT BASE - ENTREGA CRISTIAN JUAREZ

Este proyecto son los desafios levantados para la materia IIOT en la especialización de internet de las cosas. 
A partir de un fork del repositorio base de la materia se hacen distintas modificaciones al código para cumplir con los desafios propuestos.

## Desafio 1 - auto_register

Se cambia la implementación del firmware para que el dispositivo haga post con su device id harcodeada a /device para que el backend lo registre.

## Desafio 2 - api_port

Se cambia el framework y el lenguaje del monolito por python y fastapi.

## Desafio 3 - fix key

Se arreglo el código del ESP para que mande el key correctamente.

## Desafio 4 - pressure

Se cambio la métrica de humedad por la de presión.
